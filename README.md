# Legal Vakta - Criminal Case Research Assistant

Legal Vakta is an agentic RAG system for researching Supreme Court criminal
judgments. It loads judgment PDFs from `data/pdfs/**/*.pdf`, chunks and embeds
them with local sentence-transformer embeddings, stores them in FAISS, and uses
a LangGraph retrieval-and-answering workflow for grounded legal research.

This assistant is for research support, not legal advice.

## Architecture

```text
data/pdfs/**/*.pdf
        |
        v
src/ingestion/pdf_loader.py
        |
        v
src/ingestion/text_cleaner.py
        |
        v
src/retrieval/vectorstore.py  ->  vectorstore/index.faiss + index.pkl
        |
        v
src/retrieval/retriever.py
        |
        v
src/agent/graph_builder.py
        |
        +--> main.py
        +--> src/ui/app.py
```

## Setup

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

If your PDFs are currently in top-level `pdfs/`, copy them into the target
layout:

```bash
python scripts/download_pdfs.py
```

Create the selected metadata CSV:

```bash
python scripts/create_dataset.py
```

Build the FAISS index:

```bash
python scripts/build_index.py
```

Run the Streamlit app:

```bash
streamlit run src/ui/app.py
```

Run the CLI:

```bash
python main.py
```

## Demo Flow

1. Open the Streamlit UI.
2. Ask a question such as: "Find judgments discussing benefit of doubt in
   criminal appeals."
3. Legal Vakta retrieves relevant chunks from indexed PDFs.
4. The answer is generated with source filenames, case years, and page metadata.

## Notes

- The default LLM is local Ollama model `llama3.2`.
- The default embedding model is `sentence-transformers/all-MiniLM-L6-v2`.
- `vectorstore/index.faiss` and `vectorstore/index.pkl` are generated by
  `scripts/build_index.py`.
